# Instagram制作部（instagram）

Instagram「ひとこと日和」で、eFootballの情報を発信する部署です。AI社員10人で回しています。

## 中身の地図

| ファイル | これは何？ |
|---|---|
| COMPANY.md | この部署のルール。事実確認のやり方、投稿前のチェック、やってはいけないこと |
| agents.md | AI社員10人の役割表（秘書・リサーチ・企画・台本・レビュー・編集・デザイン・分析・キャプション/投稿・コメント返信） |
| build_potw.py | POTW（週間ベストイレブン）の投稿画像を作るプログラム |
| build_showtime.py | Show Timeガチャの投稿画像を作るプログラム |
| build_blackfriday.py | ブラックフライデーの投稿画像を作るプログラム |
| skills/ | 仕事のやり方メモ（リール・カルーセル制作の手順など） |

## この部署の約束

- ガチャの期間と総合値は、必ず公式などの出典で確認してから書く
- 誇張しない（「絶対当たる」などは書かない）
- 投稿は社長の最終確認があってから

会社全体のことは [../STRUCTURE.md](../STRUCTURE.md) を見てください。
