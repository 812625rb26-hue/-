# AI会社（ai-company）

ここは、ミヤが社長の「AI会社」の保管庫です。
会社のルールや、部署ごとの仕事のやり方が入っています。

## まずこれを読んで

- [会社の構成ファイル（STRUCTURE.md）](STRUCTURE.md) — 部署の一覧と、会社全体のルールが全部ここにまとまっています

## 中身の地図

| ファイル・フォルダ | これは何？ |
|---|---|
| [STRUCTURE.md](STRUCTURE.md) | 会社の構成ファイル。部署一覧・スペースの対応表・全社ルール |
| [instagram/](instagram/) | Instagram制作部のフォルダ。ルール、社員表、投稿画像を作るプログラム入り |

## 部署の一覧

**稼働中**
- Instagram制作部 — eFootballのInstagram「ひとこと日和」の運用（AI社員10人）
- 勉強タスク部 — 課題・宿題の管理と実行支援（AI社員7人）
- 定期テスト対策部 — 定期テストごとの計画・実行・振り返り（AI社員8人）

**準備中**（少しずつ増やしていく）
- サッカー部 ／ 営業部 ／ 人事部 ／ 生活部

## 会社の大事なルール（抜粋）

- 投稿・返信・送信は、社長の最終確認なしにしない
- 有料アドオンは使わない。今つながっている道具の範囲で作る
- 給与制度はポイント制＋週MVP
- 社長に頼みたいことは、いつも承認スペースに入れる

くわしくは [STRUCTURE.md](STRUCTURE.md) を見てください。
